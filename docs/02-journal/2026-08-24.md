## Appris

### Documenter avec Git, GitHub et GitHub Pages

- **Découverte du processus de documentation avec Git, GitHub et GitHub Pages :**
> *-Git conserve l'historique et GitHub permet de mettre l'historique en ligne et de partager le travail .*  
> *-Un commit seul ne met pas les modifications en ligne : il faut synchroniser avec le dépôt distant .*


- **Création et Préparation du dépôt de travail avec VsCode et Git :**
> *-VsCode sert à rédiger et modifier un fichier*  
> *-Git conserve l'historique des modifications localement .*    
> *-Pratique des principales étapes de Git : Synchronisation, modification, indexation, commit et synchronisation .*  
> *-La publication peut avoir un retard d'environ **1 à 2 minnuites***

- **Découverte du langage Markdown et sa synthaxe de base**

## Raté, puis corrigé
- Difficulté à distinguer le dépôt local du dépôt distant.
- Confusion entre le Git et le GitHub 
- La non maîtrise des différentes étapes de Git

## Décidé

- Utiliser Markdown pour les journaux afin de conserver une documentation lisible et facilement suivie dans Git 
- Utiliser la convention de commit `docs(journal):...`pour les entrées de journal.
